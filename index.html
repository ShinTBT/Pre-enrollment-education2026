お題画像 ランダム出題管理

Google Driveのフォルダから画像を取得し、出題範囲を指定して学生用URLを発行します。

1 Google Drive フォルダの読み込み

Google Apps Script（ウェブアプリ）用コード：

function doGet(e) {
  const folderId = e.parameter.folderId;
  if (!folderId) return createJson({ error: 'フォルダIDが未指定です' });
  try {
    const folder = DriveApp.getFolderById(folderId);
    const files = folder.getFiles();
    const list = [];
    while (files.hasNext()) {
      const f = files.next();
      if (f.getMimeType().startsWith('image/')) {
        list.push({ id: f.getId(), name: f.getName() });
      }
    }
    list.sort((a, b) => a.name.localeCompare(b.name, 'ja'));
    return createJson({ files: list });
  } catch (err) {
    return createJson({ error: err.message });
  }
}
function createJson(obj) {
  return ContentService.createTextOutput(JSON.stringify(obj))
    .setMimeType(ContentService.MimeType.JSON);
}

2 出題範囲の選択（0 / 0 枚選択中）

STEP 1 でGoogle Driveフォルダを読み込むと、ここに画像一覧が表示されます。
