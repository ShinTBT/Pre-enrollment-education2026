STEP 1

Google Drive からの画像取得

APIキーを公開せずに安全に画像一覧を取得できる推奨方式です。Google Apps ScriptでデプロイしたWebアプリのURLを入力してください。

GASコードと簡単な設置手順を表示する クリックで開閉
  1. Google Driveでお題用画像を入れたフォルダを開き、URL末尾の folders/【ここの文字列】（フォルダID）をコピーします（フォルダ共有は「リンクを知っている全員：閲覧者」に設定）。
  2. Google Apps Script (script.new) を開き、下のコードを貼り付けてフォルダIDを書き換えます。
  3. 右上の「デプロイ」＞「新しいデプロイ」＞種類の選択「ウェブアプリ」を選び、アクセスできるユーザーを「全員」にしてデプロイします。
  4. 発行された「ウェブアプリURL」を上の入力欄に貼り付けて「画像を読み込む」を押します。
function doGet() {
  const FOLDER_ID = "ここにGoogleDriveのフォルダIDを貼り付け";
  const folder = DriveApp.getFolderById(FOLDER_ID);
  const files = folder.getFiles();
  const images = [];

  while (files.hasNext()) {
    const file = files.next();
    if (file.getMimeType().indexOf("image/") === 0) {
      images.push({
        id: file.getId(),
        name: file.getName()
      });
    }
  }

  images.sort((a, b) => a.name.localeCompare(b.name, "ja"));

  return ContentService
    .createTextOutput(JSON.stringify({ files: images }))
    .setMimeType(ContentService.MimeType.JSON);
}

Google Cloudで発行した「Google Drive API」有効化済みのAPIキーと、「リンクを知っている全員」に共有されたGoogle DriveフォルダのURL（またはID）を入力してください。
